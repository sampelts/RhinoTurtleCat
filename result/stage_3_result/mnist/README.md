# Saved MNIST Results

`mnist_simple_full_v1` is the reproducible 10-epoch MNIST run reported in the
Stage 3 report. It trained on all 60,000 supplied training images and evaluated
the separate 10,000-image test split once.

The run achieved 98.61% test accuracy (9,861 correct predictions out of 10,000).
The folder includes the configuration, epoch-by-epoch history, final metrics,
combined learning curve, and the loss-only convergence plot. The trained
`final.pt` checkpoint is intentionally excluded because it is not needed to
inspect the reported results and is regenerated by `script_mnist.py`.
